本ページでは、各 Istio 機能の成熟度とサポートレベルを示します。これらのステージはプロジェクト全体ではなく、各機能ごとに適用されます。以下は、それぞれの段階を示すラベルの概要です。

## 機能段階の定義 {#feature-phase-definitions}

|                  | 実験的 (Experimental)                                                                                                                                                                                                                                                                                                         | アルファ (Alpha)                                                                                                                                                                                                                                                                                                         | ベータ (Beta)                                                                                                                                                                                                                                                                                                                                                                                                                             | 安定版 (Stable)                                                                                           |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 目的             | この機能は積極的に開発中であり、ユーザー向け API が変更される可能性があります。実験的機能のデプロイは極めて慎重に行い、本番環境ではなくテスト環境での利用を推奨します。移行作業が必要になる場合があります。                                                                                                                   | 設計や機能に関するフィードバックを得るため、または試験的な設計の実装状況を確認するために提供されます。開発者やエキスパートユーザー向けです。                                                                                                                                                                             | 本番環境でのソリューションを評価するために提供されますが、長期的なコミットメントはありません。実用性、パフォーマンス、可用性などを評価するための段階で、すべてのユーザーが対象です。                                                                                                                                                                                                                                                      | 本番で検証され、信頼性が高い段階です。                                                                    |
| 安定性           | バグが存在する可能性があります。利用により問題が発生する場合があります。デフォルトでは無効です。                                                                                                                                                                                                                              | バグが存在する可能性があります。利用により問題が発生する場合があります。デフォルトでは無効です。                                                                                                                                                                                                                         | コードは十分にテストされています。本番環境での利用が安全です。                                                                                                                                                                                                                                                                                                                                                                            | コードは十分にテストされ、安定しています。本番環境で広く安全に利用できます。                              |
| パフォーマンス   | パフォーマンス特性は不明です。実験的機能を有効にするとパフォーマンスに悪影響を及ぼす可能性があります。                                                                                                                                                                                                                        | パフォーマンス要件は設計の一部として評価されます。                                                                                                                                                                                                                                                                       | パフォーマンスやスケーラビリティの特性を備えていますが、注意点がある場合もあります。                                                                                                                                                                                                                                                                                                                                                      | パフォーマンス（レイテンシ/スケール）は定量化・記録され、劣化しないことが保証されます。                   |
| サポート         | 後方互換性は保証されません。Istio コミュニティはこの機能の改良・保守・完成を約束せず、予告なく将来のリリースで削除される場合があります。                                                                                                                                                                                      | 後方互換性は保証されません。Istio はこの機能の完成を約束しません。予告なく将来のリリースで削除される場合があります。                                                                                                                                                                                                     | 詳細は変更される可能性がありますが、全体の機能は削除されません。Istio は今後の安定版で何らかの形でこの機能を完成させることを約束します。通常は 3 ヶ月以内ですが、場合によってはそれ以上かかることもあります。バージョンは少なくとも 1 つのサポート対象リリースサイクル（通常 3 ヶ月）で 2 つの連続バージョン（例: v1alpha1 と v1beta1、または v1beta1 と v1）を同時にサポートし、ユーザーが十分にアップグレード・移行できるようにします。 | この機能は多くの今後のリリースでも継続して提供されます。                                                  |
| 廃止ポリシー     | なし。機能は予告なく削除される場合があります。                                                                                                                                                                                                                                                                                | なし。機能は予告なく削除される場合があります。                                                                                                                                                                                                                                                                           | 弱い。機能削除の 3 ヶ月前に通知されます。                                                                                                                                                                                                                                                                                                                                                                                                 | 強い。機能削除は 1 年前に通知される必要がありますが、通常は代替機能へのアップグレードパスが提供されます。 |
| バージョン管理   | API バージョン名に dev（例: v1dev1）が含まれます。                                                                                                                                                                                                                                                                            | API バージョン名に alpha（例: v1alpha1）が含まれます。                                                                                                                                                                                                                                                                   | API バージョン名に beta（例: v1beta1）が含まれます。                                                                                                                                                                                                                                                                                                                                                                                      | API バージョンは `vX`（例: v1）の形式です。                                                               |
| 利用可能性       | この機能はメインの Istio リポジトリに存在する場合としない場合があります。Istio のリリースに含まれる場合も含まれない場合もあり、含まれている場合はデフォルトで無効です。利用には明示的なフラグが必要です。                                                                                                                     | この機能は Istio リポジトリにコミットされ、公式リリースに含まれます。利用には明示的なユーザー操作（フラグ、設定リソース、明示的なインストールや API 呼び出し）が必要です。無効化時はシステムの安定性に影響しません。                                                                                                     | 公式 Istio リリースでデフォルト有効です。                                                                                                                                                                                                                                                                                                                                                                                                 | ベータと同じです。                                                                                        |
| 対象             | 他の開発者と機能や概念実証で密接に協力する場合。                                                                                                                                                                                                                                                                              | 早期フィードバックを提供したい開発者やエキスパートユーザー向け。                                                                                                                                                                                                                                                         | 機能に関するフィードバックを提供したいユーザー向け。                                                                                                                                                                                                                                                                                                                                                                                      | すべてのユーザー。                                                                                        |
| 完全性           | 機能の互換性は限定的です。概念実証として提供されます。                                                                                                                                                                                                                                                                        | 一部の API 操作や CLI コマンドが未実装の場合があります。API レビュー（通常のコードレビューに加えた詳細な API レビュー）は不要です。                                                                                                                                                                                      | すべての API 操作と CLI コマンドが実装されている必要があります。エンドツーエンドテストが完全かつ信頼性があります。API は徹底的なレビューを受けており、完全と見なされますが、テスト中に新たな API 課題が発見される場合もあります。                                                                                                                                                                                                         | ベータと同じです。                                                                                        |
| ドキュメント     | 実験的機能は自動生成リファレンスで「実験的」または非公開としてマークされます。                                                                                                                                                                                                                                                | アルファ機能は自動生成リファレンスで「alpha」とマークされます。機能の説明、利用方法、制限・警告、設計文書へのリンクなど基本的なドキュメントが必要です。                                                                                                                                                                  | Istio.io に完全な機能ドキュメントが公開されます。ベータ文書には例、チュートリアル、用語集なども含まれます。                                                                                                                                                                                                                                                                                                                               | ベータと同じです。                                                                                        |
| アップグレード性 | 実験的機能のアーキテクチャやセマンティクスは新バージョンで変更される場合がありますが、アップグレード時の後方互換性は保証されません。API バージョンの増加はリリースサイクルより速い場合があり、開発者は後方互換性のために複数バージョンを維持する必要はありません。不互換な変更時は API バージョンを増やすことが推奨されます。 | アルファ機能のアーキテクチャやセマンティクスは将来のリリースで変更される場合があり、既存の Istio インストールで設定オブジェクトを維持する必要はありません。API バージョンの増加はリリースサイクルより速い場合があり、開発者は複数バージョンを維持する必要はありません。不互換な変更時は API バージョンを増やすべきです。 | アーキテクチャやセマンティクスは将来のリリースで変更される場合があります。その際はアップグレードパスが記録されます。場合によってはオブジェクトが自動変換されることもありますが、手動アップグレードが必要な場合もあり、その際はプロジェクトが手順を文書化します。                                                                                                                                                                          | 後方互換性のある変更のみが許可されます。                                                                  |
| テスト           | この機能の存在は他のリリース済み機能に影響を与えてはなりません。                                                                                                                                                                                                                                                              | この機能は単体テストと統合テストでカバーされており、有効化時も安定しています。すべてのケースを網羅していない場合もありますが、主要なケースはカバーされています。テストカバレッジは 70%以上です。無効化時はシステム性能に影響しません。                                                                                   | 統合テストはエッジケースや一般的なユースケースもカバーします。すべての問題は統合テストで検証され、エンドツーエンドテストも含まれます。テストカバレッジは 80%以上です。                                                                                                                                                                                                                                                                    | ベータの超集合で、ベータ期間中に発見された問題もテストされます。テストカバレッジは 90%以上です。          |
| 信頼性           | ユーザーは信頼性を期待すべきではありません。未テストの機能が含まれる場合があります。                                                                                                                                                                                                                                          | この機能は比較的新しく、エンドツーエンドテストが不十分な場合もあるため、有効化により Istio の不安定なバグが発生する可能性があります（例：コントロールループのバグで大量のオブジェクトが作成され API ストレージが枯渇する等）。                                                                                           | エンドツーエンドテストがあるため、有効化しても他の機能に新たなバグが発生することはありません。比較的新しいため小さなバグが残る場合もあります。                                                                                                                                                                                                                                                                                            | 高い。十分にテストされ、すべての用途で安定して信頼できます。                                              |
| 推奨ユースケース | 短期的な開発やテスト環境で、ユーザーからの早期フィードバックを得ることを目的としています。                                                                                                                                                                                                                                    | 複雑なアップグレードや長期サポートがないため、短期的な開発やテスト環境での利用を推奨します。                                                                                                                                                                                                                             | 開発やテスト環境での利用、本番環境での機能評価の一環としてフィードバックを提供する場合に推奨されます。                                                                                                                                                                                                                                                                                                                                    | すべての用途。                                                                                            |
