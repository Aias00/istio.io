Ambient モードで Istio をすぐに試したいですか？[入門ガイドをお読みください](/ja/docs/ambient/getting-started/)！

Istio のインストール方法は 2 種類あります。どちらの方法を選ぶべきかは、本番要件や他のソフトウェアのインストール方法によって異なります。
選択に迷った場合は、[どの Istio インストール方法を使うべきですか？](/ja/about/faq/#install-method-selection) の FAQ ページをご覧ください。
