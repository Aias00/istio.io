Istio サービスメッシュは論理的に**データプレーン**と**コントロールプレーン**に分かれます。

- **データプレーン** は、Sidecar としてデプロイされるスマートプロキシ（[Envoy](https://www.envoyproxy.io/)）の集合です。これらのプロキシは、マイクロサービス間のすべてのネットワーク通信を調整・制御します。また、すべてのメッシュトラフィックのテレメトリーを収集・報告します。

- **コントロールプレーン** は、プロキシの管理と構成を行い、トラフィックルーティングを制御します。

## コンポーネント {#components}

以下のセクションでは、Istio の各コアコンポーネントの概要を説明します。

### Envoy

Istio は [Envoy](https://www.envoyproxy.io/) プロキシの拡張版を使用します。Envoy は C++ で開発された高性能プロキシで、サービスメッシュ内のすべてのサービスのインバウンドおよびアウトバウンドトラフィックを調整します。Envoy プロキシは、データプレーントラフィックとやり取りする唯一の Istio コンポーネントです。

Envoy プロキシはサービスの Sidecar としてデプロイされ、以下のような多くの組み込み機能をサービスに論理的に追加します：

- 動的サービスディスカバリ
- ロードバランシング
- TLS 終端
- HTTP/2 および gRPC プロキシ
- サーキットブレーカー
- ヘルスチェック
- パーセンテージベースの段階的リリース
- フォールトインジェクション
- 豊富なメトリクス

この Sidecar デプロイにより、Istio はポリシー決定を実行し、豊富なテレメトリーを抽出して監視システムに送信し、メッシュ全体の挙動を可視化できます。

Sidecar プロキシモデルにより、既存のデプロイに Istio 機能を追加する際、アーキテクチャの再設計やコードの書き換えが不要です。

Envoy プロキシによって有効化される Istio の主な機能やタスクには、以下が含まれます：

- トラフィック制御機能：HTTP、gRPC、WebSocket、TCP の豊富なルーティングルールによる細粒度のトラフィック制御
- ネットワークレジリエンス機能：リトライ設定、フェイルオーバー、サーキットブレーカー、フォールトインジェクション
- セキュリティと認証機能：セキュリティポリシーの適用、API で定義されたアクセス制御やレート制限の強制
- WebAssembly ベースのプラガブル拡張モデル：カスタムポリシー実行やメッシュトラフィックのテレメトリー生成を可能にします

### Istiod

Istiod はサービスディスカバリ、構成、証明書管理を提供します。

Istiod はトラフィック制御ルールを Envoy 固有の構成に変換し、ランタイムで Sidecar に配信します。
また、プラットフォーム固有のサービスディスカバリを抽象化し、[Envoy API](https://www.envoyproxy.io/docs/envoy/latest/api/api) に準拠した Sidecar で利用できる標準フォーマットに統合します。

Istio は Kubernetes や VM など、さまざまな環境のディスカバリをサポートできます。

Istio の[トラフィック管理 API](/ja/docs/concepts/traffic-management/#introducing-istio-traffic-management)を使って、
Istiod による Envoy 構成を再構築し、サービスメッシュ内のトラフィックをより細かく制御できます。

Istiod の[セキュリティ](/ja/docs/concepts/security/)は、組み込みの ID・証明書管理により、サービス間およびエンドユーザー認証を強力に実現します。Istio を使えば、未暗号化のトラフィックをサービスメッシュ内でアップグレードできます。
運用者は、レイヤ 3/4 の不安定なネットワーク識別子ではなく、サービス ID に基づいてポリシーを適用できます。
また、[Istio の認可機能](/ja/docs/concepts/security/#authorization)を使って、サービスへのアクセス制御も可能です。

Istiod は証明書認証局（CA）として機能し、データプレーンで安全な mTLS 通信を可能にする証明書を発行します。
