## どうやって参加する？{#how-do-you-want-to-get-involved}

{{% involve_block title="質問する" subtitle="Istio コミュニティで交流する方法はたくさんあります。" icon="user" %}}

1. 遭遇した具体的な問題は [**Stack Overflow**](https://stackoverflow.com/questions/tagged/istio) の **エキスパート** に質問しましょう。
2. [**Istio ディスカッションボード**](https://github.com/istio/istio/discussions) では多くの Istio ユーザーが活発に参加しています。質問や議論にご参加ください。
3. [**Slack**](https://slack.istio.io/) に参加して、他の Istio コミュニティメンバーとリアルタイムで交流しましょう。
   {{% /involve_block %}}

{{% involve_block title="議論に参加" subtitle="Istio について語りたいことがたくさんあります。あなたの声を歓迎します！" icon="events" %}}

1. **イベントに参加しよう！** [スケジュールはこちら](https://calendar.google.com/calendar/embed?src=i10ogf58krfbrsjai5qi16g4do@group.calendar.google.com) で今後のイベントをチェック！
2. [**Twitter - @IstioMesh**](https://twitter.com/IstioMesh) もフォローしてください。
   {{% /involve_block %}}

{{% involve_block title="バグとセキュリティ" subtitle="バグ報告やセキュリティ脆弱性の報告で Istio の改善にご協力いただきありがとうございます。" icon="security" %}}

1. [**バグ報告の方法**](/ja/docs/releases/bugs/) をご覧ください。コードでもドキュメントでも適用されます。
2. Istio セキュリティチームは **脆弱性報告** に迅速に対応します。[issue の提出方法](/ja/docs/releases/security-vulnerabilities/) をご覧ください。
   {{% /involve_block %}}

{{% involve_block title="コントリビューターになる" subtitle="コード、ドキュメント、コミュニティ：Istio への貢献を歓迎します！これらのリンクから始めましょう。" icon="contribution" %}}

1. Istio の[コード規範](https://github.com/istio/community/blob/master/CONTRIBUTING.md#code-of-conduct)と[コントリビューションガイド](https://github.com/istio/community/blob/master/CONTRIBUTING.md)に目を通してください。
2. コード、ドキュメント、その他どの分野でも貢献したい方は、[Istio コミュニティ README](https://github.com/istio/community/blob/master/README.md) が **コントリビューターの出発点** です。
3. [istio-team-drive-access@ Google Group](https://groups.google.com/forum/#!forum/istio-team-drive-access) に参加して [**技術資料や作業ドキュメント**](https://drive.google.com/drive/folders/1l_zqgBq_yfc1PfbJiWsFubXBtAz22sau) にアクセスできます。
4. [**ワーキンググループ**](https://github.com/istio/community/blob/master/WORKING-GROUPS.md) に参加できます。ドキュメント、セキュリティ、ネットワークなど、興味のある分野に特化したグループです。
5. **中国語ドキュメント**の翻訳に興味がありますか？[Cloud Native Community](https://cloudnative.to) へどうぞ。
   {{% /involve_block %}}

{{% involve_block title="運営と計画を知る" subtitle="Istio にはプロジェクトを監督する2つの主要な委員会があります：Steering Committee と Technical Oversight Committee。" icon="magnifier" %}}

1. プロジェクトのガバナンスと広報は [**Istio Steering Committee**](https://github.com/istio/community/tree/master/steering) が担当しています。
2. 技術的な指針とプロジェクト計画は [**Istio Technical Oversight Committee**](https://github.com/istio/community/blob/master/TECH-OVERSIGHT-COMMITTEE.md) が担当しています。
   {{% /involve_block %}}
